# Tonia Game v2.2 (TON-Only Edition)
Cloudflare Workers + Durable Object + Telegram WebApp + Tonkeeper Direct Deposit & On-Chain Verification.
- All balances, bets, rewards, missions, referrals, leaderboards, and withdrawals operate strictly in TON.
- Min/Max entry across games: 0.01 TON to 50 TON.
- Default missions include referral milestones (3 -> 0.01 TON, 5 -> 0.04 TON, 9 -> 0.09 TON), 5 consecutive wins at >=4x with >=0.1 TON stake (0.1 TON reward), and 7 Arena entries with at least 3 consecutive wins.
- Admin panel supports editing TON deposit address & memo, adding/removing bonuses, adding/removing/toggling missions, and sending broadcast messages to all users.
